# Exam PDF archive

Place past midterm PDFs here. The GSI dashboard opens them via deep links from [`../data/exam_manifest.json`](../data/exam_manifest.json) using the fragment form `exams/[FILE].pdf#page=N`.

## Expected filenames (from the current manifest)

| File | Used by |
| --- | --- |
| `MT1_Fall2024.pdf` | FA24-MT1-Q2 (page 3) |
| `MT1_Spring2025.pdf` | SP25-MT1-Q4 (page 5) |
| `MT2_Fall2024.pdf` | FA24-MT2-Q1 (page 2) |

Optional later additions often follow the same pattern:

- `MT2_Spring2025.pdf`

## Rules

- **Do not commit placeholder or invented PDF binaries.** Add real course midterms only.
- Keep filenames stable once linked in `exam_manifest.json`.
- After adding a PDF, verify the dashboard **Open Past Exam** link lands on the correct page in the browser PDF viewer.
- Archive is public read (students may open past midterms from the Pages site).
