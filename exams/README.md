# Exam PDF archive

Past practice exams (and solutions) from the course Resources export:

```text
exams/
  midterm1/   # Midterm 1 practice exams + _sol.pdf siblings
  midterm2/   # Midterm 2 practice exams + _sol.pdf siblings
  final/      # Final practice exams + solutions (+ Part I notes)
```

There is **no `midterm3/`** folder — the export had Midterm 1, Midterm 2, and Final only (Kurt confirmed).

## Naming scheme

Flat folders with **sibling `_sol.pdf` files**:

| Pattern | Example |
| --- | --- |
| Exam | `midterm1/MT1_Fall2024.pdf` |
| Solutions | `midterm1/MT1_Fall2024_sol.pdf` |
